# OB01 — Классы и объекты в Python

Учебный проект курса «Программист на Python».

Тема №4 — ООП в Python.
Урок №1 — введение в ООП, классы и объекты классов.

## Основное задание

Менеджер задач на основе класса Task:
- описание задачи;
- срок выполнения;
- статус выполнения;
- добавление задач;
- отметка выполненных задач;
- вывод текущих задач.

## Дополнительное задание

Магазины на основе класса Store:
- название и адрес магазина;
- ассортимент товаров и цены;
- добавление и удаление товаров;
- получение и обновление цены;
- создание не менее трёх магазинов;
- проверка работы методов.
